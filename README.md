# Página Pessoal — Mariana Laura Gonçalves Campos Rufo

Atividade Prática 2 da disciplina **GAC116 - Programação Web**, UFLA.

Portfólio pessoal desenvolvido em duas versões equivalentes, cada uma usando
um framework CSS diferente para fins de comparação:

- **`/bootstrap`** — versão construída com [Bootstrap 5](https://getbootstrap.com/)
- **`/outro-framework`** — versão construída com [Bulma](https://bulma.io/)

O arquivo `index.html` na raiz é apenas uma página de entrada que dá acesso às
duas versões.

## Estrutura

```
pagina-pessoal/
├── bootstrap/
│   ├── index.html
│   └── assets/

│   ├── index.html
│   └── assets/
│       ├── css/style.css
│       ├── js/script.js
│       └── img/
├── index.html
├── README.md
└── LICENSE
```

## Funcionalidades

- Layout responsivo (mobile, tablet e desktop)
- Tema claro e escuro, com alternância pelo botão no menu e memória da
  escolha do visitante (`localStorage`)
- Seções: Sobre, Habilidades e Contato
